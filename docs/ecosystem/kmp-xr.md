## Overview

As intelligent display glasses and spatial computing headsets expand, mobile engineers need multiplatform abstractions for spatial panels, 3D volumes, and heads-up displays without rewriting domain and networking layers.

`kmp-xr` provides:
- Jetpack Compose Glimmer bindings for smart glasses.
- Spatial panel layouts and projected hardware lifecycle management.
- Multiplatform spatial audio and sensor telemetry abstractions.
